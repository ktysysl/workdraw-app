# WorkDraw — downloads / indirmeler

**English** — WorkDraw is a diagram, system-tree and technical drawing board for Windows. Draw shapes and connectors, build tables, add QR codes, sketch architecturally, and pick from 688 symbols (electrical, IT, broadcast, automation and more). It has layers, work areas (A0–A6 and custom sizes, with fit / stretch and an overlap check), project tabs, Visio (`.vsdx`) import and export, PNG / SVG / PDF output, and it can publish a page that opens on a phone through a QR code. The interface is in **English and Turkish** — switch any time from *View → Türkçe / English*, no restart needed.

Grab the latest installer from the [Releases](../../releases) page: download the `.zip`, unzip it and run the setup. Project files use the `.wdf` extension.

**Türkçe** — WorkDraw, Windows için bir şema, sistem ağacı ve teknik çizim tahtasıdır. Kutu ve bağlantı çizer, tablo kurar, QR kod ekler, mimari çizim yapar; 688 sembol (elektrik, bilişim, yayın, otomasyon…) hazır gelir. Katmanlar, çalışma alanları (A0–A6 ve özel ölçüler; sığdırma / germe ve çakışma kontrolü), proje sekmeleri, Visio (`.vsdx`) içe ve dışa aktarma, PNG / SVG / PDF çıktısı ve çizim sayfasını QR koduyla telefonda açacak şekilde yayınlama özelliği vardır. Arayüz **Türkçe ve İngilizce** — *Görünüm → Türkçe / English* ile anında değişir, yeniden başlatmaya gerek yok.

En son kurulum dosyasını [Releases](../../releases) sayfasından indirin: `.zip` dosyasını açıp kurulumu çalıştırın. Proje dosyalarının uzantısı `.wdf`.

## Requirements / Gereksinimler

- Windows 10 or 11 (64-bit) / Windows 10 veya 11 (64-bit)
- The installer follows the system language (English or Turkish) / Kurulum sihirbazı sistem dilini izler

Windows may show a SmartScreen warning because the installer is not code-signed: **More info › Run anyway**.
Kurulum dosyası imzalı olmadığı için Windows SmartScreen uyarısı çıkabilir: **Ek bilgi › Yine de çalıştır**.
